A fully responsive, full-screen analytics dashboard built with plain HTML, CSS, and JavaScript. It features a collapsible sidebar, key metric cards, an interactive activity chart, a top contributors list, and a platforms overview.

## Features

- **Full-screen layout** with a full-height sidebar and no outer card or padding
- **Responsive design** where the sidebar hides on mobile and opens with a menu button, and cards stack on smaller screens
- **Stats overview** showing Impressions, Subscribers, and Submissions
- **Activity chart** powered by Chart.js
- **Top contributors** list with progress indicators and initial-based avatars
- **Platforms section** showing growth or decline per channel
- **Clean white theme** with a teal and indigo colour palette

## Tech Stack

- HTML5
- CSS3 (Flexbox and CSS Grid)
- Vanilla JavaScript
- [Chart.js](https://www.chartjs.org/)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/khdxsohee/Analytical-Dashboard.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser. No build step or installation is required.

## Project Structure

```
Analytical-Dashboard/
├── index.html    # Layout and structure
├── style.css     # Styling and responsive rules
└── script.js     # Sidebar toggle and chart logic
```

## Customisation

- **Data:** Update the stats, contributors, and platform values directly in `index.html` or `script.js`.
- **Colours:** Change the teal and indigo values in the CSS variables at the top of `style.css`.
- **Chart:** Edit the dataset in `script.js` to plug in your own data.
